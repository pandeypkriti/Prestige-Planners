Build split: Framer builds the beautiful on-brand page. Claude builds the functionality — copy, layout, code embeds, tracking, and the CRM automations. Make.com runs the workflows.

Cost: ~$30–55/month all-in — or a leaner $10–20/mo build (see §5).

3The Pitch — Gaps to Sell Against

  1. No portfolio gallery — luxury clients buy with their eyes. Biggest gap.
  2. No booking flow — a basic contact form, no "book a free consultation."
  3. WhatsApp buried — in the UAE a floating WhatsApp button is the #1 booking channel.
  4. Founder invisible — solo brands win on a face + story; hers is hidden.
  5. Thin social proof — few testimonials, no awards/press.
  6. No single clear CTA — the page pulls three directions.
  7. Zero ads running — 100% organic; a landing page is the prerequisite before Meta spend.

4How We Build It — Framer + Claude

Framer handles the UI

  • The beautiful on-brand page (navy/gold/cream, serif headlines, smooth scroll), auto mobile-responsive
  • Publishing live + custom domain (free custom domain since Jan 2026)
  • Built-in Calendly component (Insert menu — no code) & native HubSpot form integration
  • Custom code (Meta Pixel in <head>) — a Pro-plan feature

Claude ("Claude design") handles functionality

  • All copy, on-brand + Meta-ad-optimized
  • Full page wireframe — can be designed in Figma and imported straight into Framer
  • Code embeds: Calendly, floating WhatsApp button, Meta Pixel + "Lead" event, form→webhook
  • The CRM workflows in Make.com (§7) + click-by-click Framer instructions

Honest limitation: Claude connects directly to Figma, Lovable & Higgsfield — not Framer. So Claude hands you ready-to-paste design/copy/code, or designs in Figma → you import to Framer (smoothest path).

6What Makes a Meta-Ads Page Convert

  1. One goal, one button — "Book a free consultation."
  2. Message match — page headline echoes the ad.
  3. Mobile-first & fast load (under 2–3s).
  4. Hero + CTA above the fold.
  5. Social proof — portfolio, named testimonials, logos.
  6. Short form — name, email, phone, event type/date.
  7. Tracking — Meta Pixel + Conversions API (both, per Meta 2026); capture the hidden fbclid with each lead so ads get credited.

7The CRM & Its Workflows

CRM = the business's memory. Every form submission becomes a contact card that moves along a pipeline. Recommended: HubSpot Free.

New Lead → Contacted → Consultation Booked → Proposal Sent → Won / Lost

The four workflows, built in Make.com (the glue that runs steps automatically):

Workflow 1 — New lead capture
Trigger: Framer form submitted (webhook) → Do: create HubSpot contact (New Lead) · store event type/date/budget + fbclid · email the planner.
Workflow 2 — Instant response (the UAE money-maker)
Trigger: new lead created → Do: instant WhatsApp/SMS to the planner + an auto-reply to the lead ("We'll reach out within the hour"). Speed-to-lead is the biggest conversion lever.
Workflow 3 — Booking made
Trigger: Calendly consultation booked → Do: move to Consultation Booked · add to calendar · schedule reminders (cut no-shows) · fire Meta booking event with fbclid.
Workflow 4 — After the call
Trigger: consultation complete / +1 day → Do: won → Proposal Sent + task; no-show → friendly re-book link; after the event → auto-request a Google review + testimonial (fixes the social-proof gap).
