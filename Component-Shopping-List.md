**Rule:** if it's simple motion (fade, hover, ticker, blur) → **build native**. If it's complex (layered parallax, scroll-scrubbed video, expanding accordion) → **find a component or use Homy**, then reskin.

## Priority / order to shop
1. **Decide first:** buy **Homy ($49)** and reskin (gets #1, #3, #4, video in one go) — OR assemble from free parts. Homy is the reliable path for the 4 hard ones (🔧).
2. **Build the ✅ Native ones yourself** regardless — they're cleaner and free: positioning line, gallery ticker, founder, journal hover-index, check-availability form, footer, ribbon, blur-line.
3. **Only hunt components for the 🔧 rows** if you're NOT buying Homy: hero parallax, accordion services, stacked cards, scroll-video.

## Before you paste anything
- Set your **Color Styles + Text Styles + fonts FIRST** (Frame 0) — every pasted/native piece then inherits your brand.
- **Same Framer account** = easy copy-paste between the free template and your project.
- **Code components** may ask you to trust/enable the code — accept for reputable templates.
- **Plan check:** custom domain needs **Basic (~$10/mo)**; site-wide custom code (Meta Pixel later) needs **Pro (~$30/mo)**.
- **Reskin every pasted part** so nothing looks borrowed. Mismatched fonts/colors = the #1 giveaway.

## Reality check
5 sections are ✅ **native (free, easy)**. 4 are 🔧 **hard motion** — that's what Homy or found components are for. So realistically: **Homy ($49) + your native builds = the whole site**, all reskinned to Prestige.
