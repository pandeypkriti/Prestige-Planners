# Landing Page Feature Spec — Gaps → Features That Prove Them
_Every pitch point becomes a visible feature. Landing page = v1 (now). Website = the upsell (later)._

---

## The mapping: pain → feature

### 💸 "Hard to book" → make booking impossible to miss
| Landing page (build now) | Full website (upsell) |
|---|---|
| **Sticky header** with a persistent **"Enquire on WhatsApp"** button that follows you down the page | Same sticky Enquire CTA on every page |
| **Hero CTA** — one bold WhatsApp button above the fold | **Enquiry form** (name, event type, date) → her email |
| **Floating WhatsApp bubble** on mobile (always on screen) | **"Check my date" mini-form** (date + event type) |
| **Closing CTA band** — repeats the ask at the bottom | **Click-to-call** button for phone-first clients |
| **Pre-filled WhatsApp message** ("Hi, I'd love to enquire about my event") | Live availability / booking calendar (Calendly) |

### 🏆 "Portfolio undersells" → turn photos into proof
| Landing page | Full website |
|---|---|
| **"Featured Events" section** — 3 curated cards, each = photo + event type + guest count + venue + a one-line result or quote | **Dedicated Portfolio page**, filterable: Weddings / Corporate / Showers / Yacht & Desert |
| **Hover-to-reveal** detail on each image (elegant, luxury feel) | **Individual case-study pages** — full gallery + the story + client quote |
| **Category strip** (Weddings · Corporate · Showers · Yacht/Desert) so range is instantly clear | **Before/after or "how we did it"** storytelling per event |

### 🙈 "Proof & founder hidden" → put trust front and centre
| Landing page | Full website |
|---|---|
| **Founder Spotlight** — Benafsha's photo + a warm short story (aviation → hospitality → London → Dubai) | **Full About page** + a **30-sec founder intro video** |
| **Testimonial carousel** with names + event types (not just homepage) | Testimonials **spread across every page** at decision points |
| **Trust bar** — "★★★★★ on Google · 50+ events · Featured at [venue]" | **Live Google Reviews** widget pulling real ratings |
| **Signature / personal note** for a bespoke, human touch | Press / "as featured in" logos |

### 🔍 "Can't be found" → build discovery in (no ads)
| Landing page | Full website |
|---|---|
| **Proper page title + meta description** (so Google shows "Luxury Wedding Planner Dubai", not "Event Agency") | Full **SEO**: keyword titles + meta on every page, location terms ("Dubai", "UAE") |
| **Fast load + flawless mobile** (Google ranks these) | **Blog** kept alive (~1/mo) for search traffic |
| **Embedded Instagram feed** (fresh, social proof, keeps them on-page) | **Google Business Profile** map embed + review link |
| **Pinterest "Save" buttons** on portfolio images (brides pin for months) | **Embedded TikTok / Reels** section — the #1 Dubai discovery engine |
| **Favicon + custom domain** (the polished details) | **Image alt text + sitemap** for full search visibility |

### 💎 "Looks template, not luxury" → make it feel expensive
| Landing page | Full website |
|---|---|
| **Full-width hero image or subtle video** of an elegant event | Consistent design system across all pages |
| **Elegant serif headlines + gold accents + generous white space** | Custom iconography, refined micro-copy |
| **Subtle scroll animations** (fade/rise), soft gold hover glows | Page transitions, richer motion |
| **Custom 404 + correct browser-tab title** (kills the "template" tell) | Fixes the "About Us — 1" / "Event Agency" glitches site-wide |

### 🏷️ "No pricing signal" → qualify and set expectations
| Landing page | Full website |
|---|---|
| **"How We Work" — 3 simple steps** (Enquire → Consult → We plan it all) | **Packages page** — tiers or "Investment from…" |
| **"Bespoke packages from [X]"** teaser line (optional, if she'll share) | **Downloadable price/brochure guide** (captures email = a lead) |

## ⭐ v1 LANDING PAGE — the exact feature list to build now
One page, top to bottom. This is what I'll build:

1. **Sticky header** — logo + a single gold "Enquire on WhatsApp" button
2. **Hero** — full-bleed image, luxury headline, one subline, one WhatsApp CTA
3. **Trust bar** — ★★★★★ · number of events · a venue/press mention
4. **Featured Events** — 3 mini case-study cards (photo + type + guests + venue + quote)
5. **Services strip** — Weddings · Showers · Corporate · Yacht & Desert (one line each)
6. **Founder Spotlight** — Benafsha's photo + short story (the trust-closer)
7. **Testimonial carousel** — named quotes with event types
8. **"How We Work"** — 3 steps (Enquire → Consult → We handle everything)
9. **Closing CTA band** — "Let's plan something extraordinary" + big WhatsApp button
10. **Footer** — logo, WhatsApp, email, Instagram, discreet copyright
11. **Always-on:** floating mobile WhatsApp bubble · pre-filled message · fade-on-scroll animation · flawless mobile · correct page title + favicon

_Everything here is buildable with placeholder-but-tasteful imagery today, then swapped for her real photos._

## The pitch power of this
When you show her the page, each section is a **silent answer to a problem she just felt:**
- She felt "hard to book" → she sees the sticky WhatsApp button everywhere.
- She felt "my gallery looks like stock" → she sees real captioned case studies.
- She felt "people can't see me" → she sees her own face and story done beautifully.
- She felt "it looks a bit template" → she sees something that looks like a high-end agency made it.

**You're not describing features — you're resolving tensions you created 30 seconds earlier.** That's what closes it.

_The ⚠️/🔧 items that DON'T fit on one page (Pinterest, TikTok, Google Profile, full portfolio, blog, packages) are exactly your **website upsell** — the roadmap you present after she says yes to the page._
